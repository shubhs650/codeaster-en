# EXTR_MODE operator

## 1 Purpose

Selectively extract modes from modal data structures. The modes are selected on the criterion that a modal parameter value exceeds a given threshold, and are then concatenated into a single final data structure.

A summary table of the cumulative unit effective modal masses or of the generalized masses of the retained modes can also be printed in the MESSAGE file.

Produces a data structure of type mode_meca or mode_gene depending on the type of the input modes.

<!-- page 2 -->

## 2 Syntax

```text
resu_mod [*]    =  EXTR_MODE     (
          ♦  FILTRE_MODE= _F (
                ♦  MODE   = mod                      /     [mode_gene]
                                                     /     [mode_meca]
                                                     /     [mode_meca_c]
                ♦  /   NUME_MODE       = l_mode            [l_I]
                   /   NUME_MODE_EXCLU = l_mod_ex          [l_I]
                   /   NUME_ORDRE      = l_ordre           [l_I]
                   /   TOUT_ORDRE      =   /  'OUI'
                                           /  'NON'
                   /   ♦  FREQ_MIN     =   f_min           [R]
                       ♦  FREQ_MAX     =   f_max           [R]
                       ◊  PRECISION    =   /  prec         [R]
                                           /  0.001        [DEFAUT]
                   /   ◊  CRIT_EXTR    =   /'MASS_GENE'
                                           /'MASS_EFFE'
                                           /'MASS_EFFE_UN' [DEFAUT]
                          /  ◊   SEUIL        =  rseuil    [R]
                          /  ◊   SEUIL_X      =  rseuil    [R]
                          /  ◊   SEUIL_Y   =  rseuil       [R]
                          /  ◊   SEUIL_Z   =  rseuil       [R]
                                 )
          ◊  IMPRESSION=  _F (
                ◊  CUMUL     =   /  'OUI'
                                 /  'NON'                  [DEFAUT]
                ◊  CRIT_EXTR =   /  'MASS_EFFE_UN'         [DEFAUT]
                                 /  'MASS_GENE'
                             )
          ◊  TITRE =   titre                               [l_Kn]
                                    );
```

```text
Si mod est de type [mode_gene]   alors resu_mod est de type [mode_gene]
Si mod est de type [mode_meca]   alors resu_mod est de type [mode_meca]
Si mod est de type [mode_meca_c] alors resu_mod est de type [mode_meca_c].
```

## 3 Operands

### 3.1 Keyword FILTRE_MODE

This keyword is repeated as many times as there are data structures of type mode_meca_* or mode_gene to filter and concatenate.

### 3.2 Operand MODE

Name of the mode_meca_* or mode_gene data structure to sort and concatenate with the others.

### 3.3 Filtering the modes

The user has three ways to filter the modes.

#### 3.3.1 Operands NUME_MODE / NUME_ORDRE / TOUT_ORDRE

List of the step indices or of the modal positions of the modes to keep.

#### 3.3.2 Operands NUME_MODE_EXCLU

List of the modal positions of the modes to remove.

#### 3.3.3 Operands FREQ_MIN / FREQ_MAX / PRECISION

All the modes whose frequencies lie between f_min and f_max, to the relative precision prec, are kept. f_min must be lower than f_max.

#### 3.3.4 Operand CRIT_EXTR

Choice of the parameter used as the criterion for filtering the modes. The parameters are defined in the reference documentation [R5.01.03].

If the criterion is 'MASS_EFFE_UN' or MASS_EFFE' a mode is retained as soon as one of its directional effective modal masses, unit or not, is greater than a threshold set by the user.

If the criterion is 'MASS_GENE' a mode is retained as soon as the ratio of its generalized mass to the sum of the generalized masses of the modes of the filtered structure is greater than a threshold set by the user.

These criteria are meaningful only for data structures of type mode_meca_*.

#### 3.3.5 Operands SEUIL, SEUIL_X, SEUIL_Y, SEUIL_Z

Limit value of the criterion below which the mode can be filtered out.

For the parameters currently handled, this value is a dimensionless relative value. The same threshold can be applied in all directions (keyword SEUIL ) or different thresholds can be given for the X, Y or Z directions ( SEUIL_X, SEUIL_Y, SEUIL_Z)

### 3.4 Keyword IMPRESSION

<!-- page 4 -->

This keyword prints a table of cumulative values of some parameters. These parameters may differ from those chosen in the FILTRE_MODE keywords.

#### 3.4.1 Operand CUMUL

Printing or not of the cumulative values of the modal parameter selected by CRIT_EXTR for the result data structure resu_mod.

#### 3.4.2 Operand CRIT_EXTR

Choice of the printed parameter that is accumulated. If the criterion is 'MASS_EFFE_UN' (unit effective mass), the values of the parameters 'MASS_EFFE_UN_DX', 'MASS_EFFE_UN_DY', 'MASSE_EFFE_UN_DZ' (unit effective modal mass in direction D*) of the extracted modes are accumulated separately.

If the criterion is 'MASS_GENE' the values of the parameter MASS_GENE (generalized mass) of the extracted modes are accumulated.

The parameters mentioned in this paragraph are defined more precisely in the reference documentation [R5.01.03].

<!-- chunk 3 fr=38796ef956f9 method=machine source=session:task-5.2-tier2 on=2026-10-30 -->

### 3.5 Keyword TITRE

Title attached to the result object produced by this operator [U4.03.01].

## 4 Execution

The operator checks that the parameter used for filtering exists in the input data structure mod. If this parameter is not filled in, the run stops with a fatal error. For the keyword IMPRESSION, on the other hand, if the parameters MASS_EFFE_UN_* are not filled in, only a warning is issued.

On output, the result object produced resu_mod must not be empty, otherwise the run stops with a fatal error.

The operator also checks that all the mode_meca_* or mode_gene result objects are of the same type and come from the same initial problem (same matrices).

After filtering the modes of interest, it checks that they all have a different modal position. If not, a warning message is issued. To remove these duplicated modes, use the command EXTR_MODE again with the operand NUME_MODE_EXCLU.

At present, there is no check that the data structures of type mode_meca_* correspond to the same normalization.

## 5 Printing examples

If the factor keyword IMPRESSION is present, the operator EXTR_MODE writes a number of parameters of the extracted modes in the MESSAGE file.

Printing example, with the keywords CRIT_EXTR='MASS_EFFE_UN' and CUMUL='OUI' :

```text
--------------------------------------------------------------------
CONCEPT MODESX   DE TYPE MODE_MECA   ISSU DE L OPERATEUR EXTR_MODE
                                                  M A S S E      E F
NUME_ORDRE  NUME_MODE     FREQUENCE   MASS_EFFE_UN_DX   CUMUL_DX
         1          1    2.66902D-01    4.12685D-02    4.12685D-02
         2         11    6.49621D+01    1.18667D-01    1.59935D-01
         3         19    2.56692D+02    1.02927D-02    1.70228D-01
--------------------------------------------------------------------
----------------------------------------------------------
```

<!-- page 5 -->

```text
 F E C T I V E      U N I T A I R E
MASS_EFFE_UN_DY   CUMUL_DY    MASS_EFFE_UN_DZ   CUMUL_DZ
  2.22156D-25    2.22156D-25    3.80903D-01    3.80903D-01
  4.69363D-25    6.91519D-25    3.11195D-03    3.84015D-01
  4.22168D-27    6.95741D-25    7.06977D-03    3.91085D-01
----------------------------------------------------------
```

NUME_ORDRE is the position of the mode in the data structure, NUME_MODE is the modal position in the spectrum (see operator CALC_MODES [U4.52.02]). FREQUENCE is the natural frequency of the mode. MASS_EFFE_UN_D* is the unit effective modal mass in direction * (* = X or Y or Z ). These quantities are defined in the reference documentation [R5.01.03]. CUMUL_* are the cumulative sums of the unit effective masses per direction.

Printing example, with the keywords CRIT_EXTR='MASS_GENE' and CUMUL='OUI':

```text
-------------------------------------------------------------------
CONCEPT MODESX   DE TYPE MODE_MECA   ISSU DE L OPERATEUR EXTR_MODE
                  MASSE  GENERALISEE
NUME_ORDRE  NUME_MODE     FREQUENCE      MASS_GENE  CUMUL_MASS_GENE
         1          1    2.66902D-01    1.00000D+00    1.00000D+00
         2         11    6.49621D+01    1.00000D+00    2.00000D+00
         3         19    2.56692D+02    1.00000D+00    3.00000D+00
-------------------------------------------------------------------
```

MASS_GENE is the generalized mass of the mode, defined in the reference documentation [ R5.01.03]. CUMUL_MASS_GENE is the cumulative sum of the generalized masses.

## 6 Example of use

Here is an example showing the various options of the command EXTR_MODE for a modal analysis carried out by 5 successive mode searches:

# Computation of the total mass of the structure (for checking)

```text
massestr  =  POST_ELEM (... MASS_INER = (...));
```

# Computation of the first 17 frequencies (NUME_ORDRE from 1 to 17 ; NUME_MODE from 1 to 17)

```text
mode1 =   CALC_MODES ( MATR_RIGI = rigidité,
                       MATR_MASS = masse,
                       OPTION = 'PLUS_PETITE',
                       CALC_FREQ = _F( NMAX_FREQ = 17 ));
mode1     =  NORM_MODE    (  MODE = mode1,  reuse = mode1,
                             NORME = 'TRAN_ROTA'
                          );
```

<!-- page 6 -->

# Computation of further frequencies (NUME_ORDRE from 1 to 5 ; NUME_MODE from 18 to 22)

```text
mode2 =   CALC_MODES ( MATR_RIGI = rigidité,
                       MATR_MASS = masse,
                       OPTION = 'BANDE',
                       CALC_FREQ =_F( FREQ = (20. , 25.) ),
                      );
mode2     =  NORM_MODE    (  MODE = mode2,
                             reuse = mode2,
                             NORME = 'TRAN_ROTA'
                          );
```

# Computation of further frequencies ( NUME_ORDRE from 1 to 6 ; NUME_MODE from 23 to 28)

```text
mode3 =   CALC_MODES ( MATR_RIGI = rigidité,
                       MATR_MASS = masse,
                        OPTION = 'BANDE',
                        CALC_FREQ   =_F( FREQ = (25. 30.) ),
                      );
mode3     =  NORM_MODE    (  MODE = mode3,
                             reuse = mode3,
                             NORME ='TRAN_ROTA',
                          );
```

# Computation of further frequencies ( NUME_ORDRE from 1 to 3 ; NUME_MODE from 28 to 30)

```text
mode4 =   CALC_MODES ( MATR_RIGI = rigidité,
                       MATR_MASS = masse,
                       OPTION = 'BANDE',
                       CALC_FREQ =_F( FREQ = (29. , 32.) ),
                      );
```

```text
mode4     =  NORM_MODE    (  MODE = mode4,
                             reuse = mode4,
                             NORME ='TRAN_ROTA',
                           );
```

# Computation of further frequencies (NUME_ORDRE from 1 to 6 ; NUME_MODE from 31 to 34)

```text
mode5 =   CALC_MODES ( MATR_RIGI = rigidité,
                       MATR_MASS = masse,
                       OPTION = 'BANDE',
                       CALC_FREQ =_F( FREQ = (32. , 35.) ),
                      );
mode5     =  NORM_MODE    (  MODE = mode5,
                             reuse = mode5,
                             NORME = 'TRAN_ROTA'
                          );
```

# Extraction of the modes

```text
mode  =   EXTR_MODE    (  FILTRE_MODE = _F (  MODE   =  mode1,
                                              TOUT_ORDRE   =  'OUI'  ),
                                           (  MODE   =  mode2,
                                              NUME_MODE = (18,19,20,21,22))
                                           (  MODE   =  mode3,
                                              FREQ_MIN  =  25.,
                                              FREQ_MAX  =  30.),
                                           (  MODE   =  mode4,
                                              NUME_MODE_EXCLU =   28 ),
                                           (  MODE   =  mode5,
                                              CRITERE   =  'MASS_EFFE_UN',
                                              SEUIL  =  0.005 ),
                          IMPRESSION   =_F (  CUMUL  =  'OUI' )
                       );
```
