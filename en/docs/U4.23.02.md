# CREA_MAILLAGE operator

## 1 Purpose

Create a data structure of type `maillage` from another mesh. The new mesh is created from an existing mesh by duplicating, destroying, transforming or splitting elements, or by copying a mesh (case of GEOM_FIBRE).

It produces a mesh data structure.

## 3 Risk of producing a nonconforming mesh

Several features of the command CREA_MAILLAGE can produce a nonconforming mesh. For this reason, the user must be particularly careful when using CREA_MAILLAGE to transform elements. A mesh is nonconforming when the shape functions of 2 adjacent elements do not have the same trace on their common boundary.

For example:

- 2 pentahedra assembled to form a hexahedron and placed on another hexahedron (1 quadrangle facing 2 triangles).
- 1 QUAD8 sharing an edge with 1 QUAD4 or 1 TRIA3
- 1 TRIA6 sharing an edge with 2 TRIA3

Nonconforming meshes generally lead to wrong results (at least locally).

Among the possibilities of CREA_MAILLAGE, several situations are potentially dangerous:

- Using one of the keywords QUAD_TRIA3 [§4.4.1], LINE_QUAD [§4.5], QUAD_LINE [§4.11], HEXA20_27 [§4.7], PENTA15_18 [§4.6] with the keyword GROUP_MA. If, for example, a linear mesh is partly turned into a quadratic mesh, the mesh is nonconforming on the boundary between the linear and the quadratic elements. When using the keyword GROUP_MA , take care to give all the elements involved in the transformation , in particular the skin elements; otherwise an HEXA27 could, for example, be bordered by QUAD8 skin elements .
- Using the keyword HEXA20_27 [§4.7](or PENTA15_18 [§4.6] when the mesh holds volume elements with quadrangular faces of a type different from the elements being modified. For example, when there are pentahedra or pyramids while hexahedra are modified. The risk is that, for example, a quadrangular face of an HEXA27 (9 nodes) is attached to an 8-node quadrangular face of an adjacent PENTA15.
- Using the keyword QUAD_TRIA3 when the mesh holds TRIA6 elements. In this case, the quadrangles turned into TRIA3 are incompatible with the TRIA6.

## 4 Operands

### 4.1 Operand MAILLAGE

```text
♦  MAILLAGE = ma_1
```

ma_1 is the name of the initial mesh to reproduce before “enriching" it with new elements or nodes, or "thinning" it.

Remark: The keyword MAILLAGE is required except when using the keywords ECLA_PG and GEOM_FIBRE.

### 4.2 Keyword CREA_MAILLE

```text
◊  CREA_MAILLE
```

One occurrence of this factor keyword defines a new element group made of new elements, themselves based on existing nodes. To duplicate several element groups, repeat the factor keyword CREA_MAILLE. Unlike the command DEFI_GROUP [U4.22.01], for which the mesh object always keeps the same number of elements and nodes, here the number of elements of the new mesh increases (the number of nodes stays the same because the new elements are based on existing nodes). This can make it easier to create new geometric locations so that different modeling types can be applied on the same element group.

#### 4.2.1 Operand NOM

```text
♦  NOM = noma
```

Gives the name of the new element group to create.

#### 4.2.2 Operands GROUP_MA / TOUT

```text
♦  |  GROUP_MA  = lgma,
   |  TOUT      = 'OUI',
```

The set of elements given by the user with these two keywords is duplicated, and the new elements are gathered in an element group with the name given by the keyword NOM. If the set of elements to duplicate holds duplicate elements, they are removed.

#### 4.2.1 Operands PREF_MAILLE / PREF_NUME

```text
◊  PREF_MAILLE = pre_ma
```

The value of this keyword defines the prefix of the new elements. The name of the new element is obtained by replacing the first character of the name of the element to duplicate with the text given under the keyword PREF_MAILLE. If this new name is longer than eight characters, the command stops with a fatal error message. This should normally never happen if the prefix given is a single character. This keyword is optional: the default prefix is then «E»

```text
◊  PREF_NUME =  /  ind
```

<!-- page 8 -->

If an integer ind is given under the keyword PREF_NUME, the number of the new elements is built by concatenating the uppercase text given under the keyword PREF_MAILLE and an integer obtained by incrementing ind by 1 for each new element created.

Remark: the user must choose the prefix carefully to avoid new elements having the same name as old elements. This name collision is detected by the command and stops Code_Aster.

<!-- chunk 5 fr=15a219ef6088 method=machine source=session:task-5.2 on=2026-10-30 -->

### 4.3 Keyword CREA_POI1

```text
◊  CREA_POI1
```

One occurrence of this factor keyword defines elements of type 'POI1' (single-node elements) from nodes or from nodes of elements.

#### 4.3.1 Operands TOUT / GROUP_MA /GROUP_NO

```text
♦  |  TOUT      =  'OUI',
   |  GROUP_MA  =  lgma,
   |  GROUP_NO  =  lno,
```

Every node that belongs to entities given by the user with these five keywords generates an element of type POI1. The element created has the same name as the node that carries it.

#### 4.3.2 Operand NOM_GROUP_MA

```text
♦  NOM_GROUP_MA = nom_ma
```

All the POI1 elements created this way can be gathered in one element group named nom_ma.

#### 4.3.3 How to create several POI1 elements on each node?

The POI1 elements created by the keyword CREA_POI1 have the same names as the nodes they were created from. It is therefore not possible to create several POI1 elements on one node with several occurrences of the keyword CREA_POI1.

One possible workaround is to combine CREA_MAILLAGE / CREA_POI1 with CREA_MAILLAGE / CREA_MAILLE. For example, to create 2 POI1 elements on each node of the group 'GNO1':

```text
MA2=CREA_MAILLAGE(MAILLAGE=MA1,
      CREA_POI1 =  _F(NOM_GROUP_MA='GM1', GROUP_NO='GNO1'))
MA3=CREA_MAILLAGE(MAILLAGE=MA2,
      CREA_MAILLE =_F(NOM_GROUP_MA='GM2', GROUP_MA='GM1', PREF_MAIL='S'))
```

### 4.4 Keyword MODI_MAILLE

```text
◊  MODI_MAILLE
```

One occurrence of this factor keyword transforms a set of elements.

<!-- page 9 -->

#### 4.4.1 Operand OPTION

```text
♦  OPTION =  /  'SEG3_4'
             /  'TRIA6_7'
             /  'QUAD8_9'
             /  'QUAD_TRIA3'
```

This keyword gives the transformation to perform:

1) three-node segments into four-node segments (usable for example for the modeling type 'TUYAU' [U3.11.06], 2) six-node triangles into seven-node triangles, 3) eight-node quadrangles into nine-node quadrangles, 4) quadrangles into 3-node triangles:

- elements of type QUAD4 into two elements of type TRIA3
- elements of type QUAD8 into six elements of type TRIA3
- elements of type QUAD9 into eight elements of type TRIA3

#### 4.4.2 Operands PREF_NOEUD / PREF_MAILLE / PREF_NUME

```text
◊  PREF_NOEUD = /  pre_nd,
                /  'NS',
```

The value of this keyword defines the prefix of the new nodes. The name of the new node is obtained by adding the text given under the keyword PREF_NOEUD in front of its old name. If this new name is longer than eight characters, the command stops with a fatal error message.

```text
◊  PREF_MAILLE = pre_ma
   VoirCREA_MAILLE.
◊  PREF_NUME =  /  ind,
                /  1,
```

If an integer ind is given under the keyword PREF_NUME, the number of the new nodes (new elements) is built by concatenating the uppercase text given under the keyword PREF_NOEUD (PREF_MAILLE) and an integer obtained by incrementing ind by 1 for each new node (new element) created.

Remarks: The user must choose the prefix carefully to avoid new nodes (new elements) having the same name as old nodes (old elements). This name collision is detected by the command and stops Code_Aster.

An automatic procedure that splits quadrangles into triangles can create a kind of "polarization" of the mesh: from a given QUAD mesh, all the diagonals end up oriented in the same direction.

Warning: using the option 'QUAD_TRIA3' can lead to a nonconforming mesh. See [§3].

### 4.5 Keyword LINE_QUAD

```text
◊  LINE_QUAD
```

This feature creates a quadratic mesh from a linear mesh.

<!-- page 10 -->

It can be applied to part of the mesh only (keyword GROUP_MA), but this is not recommended. See [§3].

The element groups are kept, and so are the node groups (unchanged). As when refining a mesh, the nodes created are not added to the existing node groups. If a node group corresponds to a boundary, after LINE_QUAD this group does not hold the edge middle nodes. To get a complete GROUP_NO, use for example the command DEFI_GROUP / OPTION = 'APPUI'.

#### 4.5.1 Operands GROUP_MA / TOUT

```text
♦  |  GROUP_MA  = lgma,
   |  TOUT      = 'OUI',
```

The set of elements given by the user with these two keywords is turned into quadratic elements.

Warning: using the keyword GROUP_MA is not recommended. See [§3].

#### 4.5.2 Operands PREF_NOEUD / PREF_NUME

As for MODI_MAILLE.

### 4.6 Keyword PENTA15_18

This factor keyword works like the factor keyword LINE_QUAD (same syntax). It turns PENTA15 into PENTA18 by adding nodes at the middle of the quadrangular faces.

Warning: using this keyword is not recommended if the mesh holds other types of volume elements (HEXA and PYRAM). See [§3].

### 4.7 Keyword HEXA20_27

This factor keyword works like the factor keyword PENTA15_18, for hexahedra. It turns HEXA20 into HEXA27 by adding nodes at the middle of the faces and at the center of each hexahedron.

Warning: using this keyword is not recommended if the mesh holds other types of volume elements (PENTA and PYRAM). See [§3].

### 4.8 Keyword MODI_HHO

This option creates a mesh compatible with HHO elements from any mesh. It is essential for using the HHO method on tetrahedra, prisms and pyramids. The mesh created is made of SEG3, QUAD9, TRIA7, HEXA27, TETRA15, PENTA21 and PYRAM19.

Warning: using this keyword is not recommended if it is applied to only part of the mesh, because this can produce nonconforming meshes. See [§ 3 ].

<!-- chunk 7 fr=9e12758f151f method=machine source=session:task-5.2 on=2026-10-30 -->

### 4.9 Keyword COQUE_SOLIDE

This option creates a mesh compatible with COQUE_SOLIDE elements from a mesh of HEXA8 or PENTA6 elements. It is essential for using the modeling type COQUE_SOLIDE: the new HEXA9 and PENTA7 elements hold a node at the middle of the support that carries the pinching degree of freedom. The mesh created is therefore made of SEG2, QUAD4, HEXA9, PENTA7 and TRIA3.

<!-- page 11 -->

For hexahedral elements, the keyword GROUP_MA_SURF must be given; it identifies the surface used to orient the elements. This surface can be the top or the bottom one. This is not needed for prisms, since in that configuration the TRIA3 identify the top and bottom surfaces of the shell.

Since this option creates new nodes, the keywords PREF_NOEU and PREF_NUME can be used (see §4.4.2).

### 4.10 Keyword RAFFINEMENT

This option creates a uniformly refined mesh from a given mesh. The option applies to the whole mesh to avoid any conformity problem. The principle of uniform refinement is to split each edge in two and propagate the split to the other elements. It is equivalent to the adaptation ‘RAFFINEMENT_UNIFORME’ of the macro MACR_ADAP_MAIL. Warning: the size of the mesh grows very quickly, and its quality can drop if the starting mesh is not of good enough quality. It is recommended to start from a mesh that already represents the geometry well, especially if it is curved, before refining.

```text
◊  TOUT   =  ‘OUI’ ,             [DEFAUT]
```

The refinement applies to the whole mesh.

```text
◊  NIVEAU    =  /   ind   ,            [I]
             /  1,               [DEFAUT]
```

The keyword NIVEAU gives the number of successive refinements wanted.

### 4.11 Keyword QUAD_LINE

```text
◊  QUAD_LINE
```

This feature creates a linear mesh from a quadratic mesh; it can be applied to part of the mesh only (in that case, take care with the junction of the linear and quadratic zones). See [§3].

#### 4.11.1 Operands GROUP_MA / TOUT

```text
♦  |  GROUP_MA  = lgma,
   |  TOUT      = 'OUI',
```

The elements given by the user with these two keywords are turned into quadratic elements (sic in the source; the purpose above says linear).

Warning: using the keyword GROUP_MA is not recommended. See [§3].

### 4.12 Keyword REPERE

```text
◊  REPERE
```

One occurrence of this factor keyword defines a new mesh from the old mesh by a change of coordinate system.

This feature is used in particular in the macro-command MACR_CARA_POUTRE [U4.42.02] to compute the warping constant.

<!-- page 12 -->

#### 4.12.1 Operands TABLE / NOM_ORIG / NOM_ROTA / GROUP_MA

```text
♦  TABLE = tab
```

Gives the name of the table of «geometric characteristics» that holds in particular the coordinates of the center of inertia and of the center of torsion, the nautical angles defining the principal inertia coordinate system,... This table can be obtained with the command POST_ELEM with the factor keywords CARA_GEOM or CARA_POUTRE [U4.81.22].

```text
◊  NOM_ORIG =   /   'CDG',
                /  'TORSION',
```

Gives the center of the new coordinate system: the center of gravity or the center of torsion.

```text
◊  NOM_ROTA =   /  'INERTIE',
```

Gives the direction of the new coordinate system. Only one solution is possible: the directions are those of the principal inertia coordinate system.

```text
◊  GROUP_MA =   gma
```

If NOM_ORIG = 'CDG', the name of the element group whose center of gravity is the origin of the new coordinate system can be given. If GROUP_MA is not used, the center of gravity of the whole MODELE is the origin of the new coordinate system. If NOM_ORIG = 'TORSION', the keyword GROUP_MA has no effect.

### 4.13 Keyword COQU_VOLU

```text
◊  COQU_VOLU
```

From a group of surface elements (QUAD, TRIA3), the volume mesh (HEXA8, PENTA6) is built by extrusion along the normal of the elements (at a node, the mean of the normals of the elements sharing it is taken). A single layer of elements is created. The operation applies only to linear meshes; to create a quadratic mesh, simply use CREA_MAILLAGE/LINE_QUAD afterward.

#### 4.13.1 Operands NOM

```text
♦  NOM= noma,
```

Name of the element group made of the volume elements created by this operation.

#### 4.13.2 Operands GROUP_MA

```text
♦  GROUP_MA  = lgma,
```

Element groups that make up the surface mesh to extrude.

#### 4.13.3 Operands EPAIS

```text
♦  EPAIS  = ep,
```

Thickness of the layer of elements created (thickness of the shell).

<!-- page 13 -->

#### 4.13.4 Operands PLAN

```text
♦  PLAN   =  /‘SUP’,
             /‘INF’,
             /‘MOY’,
```

Says whether the surface made of lgma is the top (SUP), bottom (INF) or mid (MOY) plane of the shell.

#### 4.13.5 Operands TRANSLATION

```text
♦  TRANSLATION  =  /‘SUP’,
                   /‘INF’,
```

When PLAN=’MOY’, says whether the initial surface made of lgma is translated to the top (SUP) or bottom (INF) skin.

#### 4.13.6 Operands PREF_MAILLE / PREF_NOEUD / PREF_NUME

As for CREA_MAILLE, except the default value, which is ‘V’.

### 4.14 Keyword CREA_FISS

```text
◊     CREA_FISS =  _F(
                ♦  NOM= nogma,                       [TXM]
                ♦  GROUP_NO_1 = gno1,                [group_no]
                ♦  GROUP_NO_2 = gno2,                [group_no]
                ♦  PREF_MAILLE   =  pre_ma ,         [Kn]
                ◊  PREF_NUME =   /  ind,             [I]
                                 /  1,               [DEFAUT]
                                 ),
```

Creates a crack with joint elements [R3.06.09] or discontinuity elements [R7.02.12] along a line defined by two node groups facing each other. The two node groups must have the same number of nodes and must first be ordered (for example with DEFI_GROUP/CREA_GROUP_NO/OPTION=’NŒUD_ORDO’) so that their numbering «starts» on the same side (see Illustration 1). A «joint» modeling type can then be assigned on these new QUAD4 elements (for example ‘PLAN_JOINT’).

The elements created have a name made of the prefix pre_ma followed by a number. For example, if PREF_MAILE=’FS’ and PREF_NUME=7, the elements created are named: FS7, FS8, …

A new GROUP_MA (named nogma) holding all the QUAD4 elements created is also created.

#### 4.14.1 Operand NOM

Name of the element group made of the volume elements created by this operation.

#### 4.14.2 Operands GROUP_NO_1 / GROUP_NO_2

Node groups that make up the lips of the crack. The node group GROUP_NO_1 carries the local nodes 1 and 2 (the first node of the group has local number 1); GROUP_NO_2 carries the local nodes 3 and 4 (the first node of the group has local number 4). Choose these node groups according to the geometry so that the local numbering of the elements is counterclockwise.

### 4.18 Keyword DECOUPE_LAC

```text
♦  DECOUPE_LAC
```

This keyword gives a mesh holding «patches» created on the element group given in GROUP_MA_ESCL. It is a preprocessing of the slave elements for contact with the LAC mortar method. Note that the elements underlying the elements of GROUP_MA_ESCL are also split. The splits of the elements PYRA5 PYRA13, PENTA6, PENTA15 and HEXA8 HEXA20 in the case DECOUPE_HEXA=' PYRA ' are «nonconforming» splits, in the sense that they introduce elements different from the split element (pyramids and/or tetrahedra) so as to add only one node per split element in the mesh.

Splitting PENTA18 is not supported.

Warning: DECOUPE_LAC must be the last command acting on the mesh. The MODI_MAILLAGE operations must be done before.

## 5 Examples

### 5.1 Duplicating elements

Let ma_1 be a mesh that already holds the elements:

```text
M1   M2   M3
```

and the element group:

```text
coque : M1   M2
```

Each element is based on the following nodes:

```text
   M1 : N1   N2   N3
   M2 : N3   N4   N5
   M3 : N4   N5   N6
ma_2 = CREA_MAILLAGE   (  MAILLAGE = ma_1,
             CREA_MAILLE =_F( NOM          = sol,
                              GROUP_MA     = 'coque',
                              PREF_MAILLE  = 'A',
                              PREF_NUME    = 100,    ),
                       )
```

After the call to the command CREA_MAILLAGE , the new mesh then holds:

- the element groups:
  - `coque` (initial)
  - `sol` = (elements: A100 A101)
- the elements are based on the following nodes:

```text
•   M1 : N1   N2   N3
•   M2 : N3   N4   N5
•   M3 : N4   N5   N6
•   A100  : N1   N2   N3
•   A101  : N3   N4   N5
```

### 5.2 Turning 6-node triangles into 7-node triangles

```text
ma_2 = CREA_MAILLAGE   (  MAILLAGE = ma_1,
          MODI_MAILLE  =  _F( GROUP_MA   = 'triangle',
                              OPTION     = 'TRIA6_7',
                              PREF_NOEUD = 'NMI',
                              PREF_NUME  = 10,    ),
                       )
```

Suppose that in ma_1 the GROUP_MA triangle is made of two elements M1, M2 with the following nodes:

```text
M1 : N1 N2 N3 N4 N5 N6
M2 : N1 N2 N7 N4 N8 N9
```

In the mesh ma_2, the two elements M1, M2 have the following nodes:

```text
M1 : N1 N2 N3 N4 N5 N6 NMI10
M2 : N1 N2 N7 N4 N8 N9 NMI11
```
