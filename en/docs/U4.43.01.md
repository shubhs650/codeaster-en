# DEFI_MATERIAU operator

## 1 Purpose

Define the physical parameters or properties of a material, used to express the constitutive laws, or the parameters associated with fatigue, damage, or simplified methods.

The physical parameters currently accepted by this operator cover the following fields: linear or nonlinear Mechanics and Thermics, Metallurgy for modeling steels, Hydration and Drying for concrete, Fluid for acoustics, Thermo-Hydro-Mechanics for modeling saturated porous media in coupled thermomechanics, and Soil Mechanics.

If needed, one material can be defined in a single call to DEFI_MATERIAU with several sets of physical parameters, in the following fields: elastic, thermal, …

It produces a data structure of type `mater`.

Remarks: The command DEFI_MATERIAU is reentrant, but each set of behavior parameters stays unique. A set of behavior parameters already present in the material cannot be replaced; the object can only be enriched.

For most material behaviors, the properties can be constant or depend on one or more external state variables (see the commands AFFE_MATERIAU and AFFE_VARC), as a function, a two-variable function or a formula. The parameters time (’INST’), plastic strain (’EPSI’) and curvilinear abscissa (’ABSC’) can be used in very particular cases; the behaviors that can depend on these parameters say so explicitly in their description.


Density. The order of magnitude is not checked. Warning: for THM modeling types in statics, only the homogenized density given in THM_DIFFU (see section 10.7.2) is taken into account. #### 4.1.4 Operands ALPHA/TEMP_DEF_ALPHA/PRECISION

```text
ALPHA = alpha
```

Isotropic thermal expansion coefficient. The thermal expansion coefficient is a mean expansion coefficient that can depend on the temperature T .

The values of the expansion coefficients are determined by dilatometry tests done at room temperature ( 0°C or more generally 20°C ).

<!-- page 14 -->

As a result, the values of the expansion coefficient are generally defined with respect to 20°C (the temperature at which the thermal strain is assumed to be zero).

Some studies need a reference temperature different from room temperature (zero thermal strain at a temperature other than room temperature). A change of reference must then be made in the calculation of the thermal strain [R4.08.01].

```text
TEMP_DEF_ALPHA = Tdef     [R]
```

The temperature at which the values of the thermal expansion coefficient were determined and given under the keyword ALPHA. This keyword becomes required as soon as ALPHA is given.

For non-THM behaviors, the thermal strain is computed by the formula [R4.08.01]: α(T)(T−T )−α(T )(T −T ) e th(T)=α^ (T)(T−T ) with α^ (T)= def ref ref def ref T−T ref and e th(T )=0 ref <!-- equation -->

Remark: A formula or a two-variable function cannot be used for ALPHA, because of the changes described above. The parameter ALPHA can ONLY depend on the temperature, and only if it is a function. To use a formula, the user must first tabulate it with the command CALC_FONC_INTERP .

```text
PRECISION =  /  prec

```

This keyword is used when the keyword TEMP_DEF_ALPHA is given.

### 14.6 Factor keywords RCCM, RCCM_FO

Definition of the quantities needed to use the simplified methods defined in the RCC-M code [R7.04.03]. These quantities are constant or functions of the parameter ’TEMP’.

#### 14.6.1 Syntax

```text
| /     RCCM    = _F (
                ◊   SY_02     =  sy,              [R]
                ◊   SM        =  sm,              [R]
                ◊   SU        =  su,              [R]
                ◊   SC        =  sc,              [R]
                ◊   SH        =  sh,              [R]
                ◊   N_KE      =  h,                  [R]
                ◊   M_KE      =  m,                  [R]
                ◊   A_AMORC   =  a,                  [R]
                ◊   B_AMORC   =  b,                  [R]
                ◊   D_AMORC   =  d,                  [R]
                ◊   R_AMORC   =  r,                  [R]
                 )
    /   RCCM_FO = _F (
                ◊   SY_02     =  sy,              [fonction]
                ◊   SM        =  sm,              [fonction]
                ◊   SU        =  su,              [fonction]
                ◊   S         =  s ,              [fonction]
                ◊   SH        =  sh,              [fonction]
                ◊   N_KE      =  h,                  [fonction]
                ◊   M_KE      =  m,                  [fonction]
                ◊   A_AMORC   =  a,                  [fonction]
                ◊   B_AMORC   =  b,                  [fonction]
                ◊   D_AMORC   =  d,                  [fonction]
                ◊   R_AMORC   =  r,                  [fonction]
                 )
```

#### 14.6.2 Operand SY_02

```text
SY_02 = sy
```

Yield strength at 0.2% plastic strain at the calculation temperature. This operand can vary with temperature.

#### 14.6.3 Operands SM/SU/SH

```text
SM = sm
```

Allowable equivalent stress of the material at the calculation temperature. This operand can vary with temperature.

```text
SU = su
```

Tensile strength of the material at the calculation temperature. This operand can vary with temperature.

```text
Sh = sh
```

Allowable stress of the material at room temperature, see POST_RCCM[U4.83.11].

Allowable stress of the material at the maximum temperature, see POST_RCCM[U4.83.11].

```text
SC =  sc
```

#### 14.6.5 Operand S

```text
S =s
```
