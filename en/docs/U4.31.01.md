# DEFI_CONSTANTE operator

## 1 Purpose

Define the value of an invariant quantity.

This operator is a convenience for every case where an object of type function is expected and the data to enter is constant. It makes it possible, for example, to define materials whose properties do not depend on temperature for commands that can handle materials whose properties vary with temperature.

Take care not to confuse this with the definition of a real parameter (e.g. a = 3.).

<!-- page 2 -->

## 2 Syntax

```text
f [fonction] =  DEFI_CONSTANTE
                (  ◊   NOM_RESU =   /  'TOUTRESU'    ,        [DEFAUT]
                                    /  nr            ,        [K8]
                   ♦   VALE =          v             ,        [R]
                   ◊   TITRE =         ti            ,        [l_Kn]
                )
```

## 3 Operands

### 3.1 Operand NOM_RESU

```text
◊  NOM_RESU = nr
```

Gives the name of the result: the function created is a function whose value is named nr (8 characters at most).

Note:

Some commands ( CALC_FONCTION , DEFI_MATERIAU …) check that the names of the parameter and of the result are consistent with their context.

### 3.2 Operand VALE

```text
♦  VALE = v
```

Value of the constant (real number).

### 3.3 Operand TITRE

```text
◊  TITRE = ti
```

Title attached to the object produced by this operator [U4.03.01].

## 4 Examples

- Define the constant function "1." :

```text
F_UN = DEFI_CONSTANTE (VALE = 1. )
```

The function F_UN represents "any kind of result" (TOUTRESU) by DEFAUT

- Define a constant function representing a constant YOUNG's modulus

```text
F_YOUNG  =  DEFI_CONSTANTE (    VALE = 2.1E11 ,
                                NOM_RESU = 'E'   )
```
