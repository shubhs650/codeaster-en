# NUME_DDL operator

## 1 Purpose

Number the unknowns of a system of linear equations. This operator also "prepares" the assembly of the matrix associated with this system of equations.

It is in this operator that the method for solving the linear systems is chosen: LDLT, conjugate gradient, multifrontal…

Produces a data structure of type nume_ddl.

<!-- page 2 -->

## 2 Syntax

```text
nu [nume_ddl] = NUME_DDL   (
   ♦  /  MODELE    =   mo,                       [modele]
          ◊  CHARGE=   lchar,                 /  [l_char_meca]
                                              /  [l_char_ther]
                                              /  [l_char_acou]
      /   MATR_RIGI =  lmel,                  /  [l_matr_elem_TEMP_R]
                                              /  [l_matr_elem_DEPL_R]
                                              /  [l_matr_elem_DEPL_C]
                                              /  [l_matr_elem_PRES_C]
```

```text
◊   INFO     =   /  1,                     [DEFAUT]
                 /  2,
                       )
```

<!-- page 3 -->

## 3 General

This command numbers the equations (and the unknowns) of the linear systems to be solved. It also prepares the assembly of the matrices, by building the pointer arrays that correspond to the storage of these matrices.

## 4 Operands

### 4.1 Operand MODELE / CHARGE

```text
♦  / MODELE = mo  , CHARGE = lchar
```

The code will number the degrees of freedom of the elements of the model mo as well as the Lagrange-multiplier degrees of freedom of the dualized kinematic conditions that may be present in the loads of the list lchar.

### 4.2 Operand MATR_RIGI

```text
♦  / MATR_RIGI = lmel
```

List of matr_elem_* used to build the numbering of the unknowns of the problem.

The purpose of this operator is to number all the degrees of freedom of the problem. These degrees of freedom are those carried by the element matrices computed by the operator CALC_MATR_ELEM (lmel).

Because the "kinematic" conditions are enforced with Lagrange multipliers, the Lagrange degrees of freedom are carried by the matr_elem computed by the option 'RIGI_MECA' (or 'RIGI_THER', ...) on the loads where the kinematic conditions are defined.

It is therefore important to give in lmel the list of all the "stiffness" matr_elem and not to forget the loads in the operator CALC_MATR_ELEM [U4.61.01].

### 4.3 Operand INFO

```text
◊  INFO =
```

/ 1 in the MESSAGE file.

  - total number of degrees of freedom, number of nodes,
  - number of LAGRANGE degrees of freedom,
  - maximum height of a column (and mean height),
  - number of stored terms (for 'MORSE' storage),
