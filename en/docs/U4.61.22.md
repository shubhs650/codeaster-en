# ASSE_MATRICE operator

## 1 Purpose

Create a matrix by assembling element matrices.

The matrix produced is "sparse"; it is stored in "morse" (compressed sparse) form.

Produces a data structure of type matr_asse_*.

<!-- page 2 -->

## 2 Syntax

```text
ma [matr_asse_*] = ASSE_MATRICE
   (  ♦   MATR_ELEM =  mel,                      /   [matr_elem_DEPL_R]
                                                 /   [matr_elem_DEPL_C]
                                                 /   [matr_elem_TEMP_R]
                                                 /   [matr_elem_PRES_C]
      ♦   NUME_DDL  =  nu,                           [nume_ddl]
      ◊   CHAR_CINE =  cha,                      /   [char_cine_meca]
                                                 /   [char_cine_ther]
                                                 /   [char_cine_acou]
      ◊   SYME     =   'OUI',
```

```text
   ◊   INFO     =   /  1,                         [DEFAUT]
                    /  2,
)
```

## 3 Operands

### 3.1 Operand MATR_ELEM

```text
♦  MATR_ELEM = mel,
```

Name of the matr_elem_* result object to assemble.

### 3.2 Numbering and storage

```text
♦  NUME_DDL = nu,
```

Specifies the numbering of the equations of the assembled system and the storage of the matrix.

### 3.3 Operand CHAR_CINE

```text
◊  CHAR_CINE = cha,
```

Name of the kinematic load to take into account in the assembled matrix, for treatment by elimination of the imposed degrees of freedom (see command AFFE_CHAR_CINE [U4.44.03]).

### 3.4 Operand SYME

```text
à  SYME = 'OUI'
```

This argument can only take the value 'OUI'. In that case, the matrix is forced to be symmetric after assembly. Thus, if the matrix K created by assembly is non-symmetric, the keyword SYME = 'OUI' makes it symmetric and replaces it with:

1 ma= KKT 2 <!-- equation -->

### 3.5 Operand INFO

```text
◊  INFO
```

Prints information on the assembled matrix

| 1 : | no printing, |
|---|---|
| 2 : | printing of the number of stored terms and of the conditioning coefficient of the 'LAGR' degrees of freedom, |

## 4 Example

```text
matas =   ASSE_MATRICE    (  NUME_DDL = nu ,
                              MATR_ELEM = mel,
                          )
```

Remark:

The element matrices of mel will be assembled following the numbering nu .

This numbering must therefore take into account all the degrees of freedom of these element matrices (in particular the degrees of freedom that correspond to the Lagrange-multiplier enforcement of the boundary conditions). One will therefore write:

```text
mel = CALC_MATR_ELEM(OPTION = 'RIGI_MECA',
                     MODELE = mo, CHARGE = condlim,)
nu = NUME_DDL(MATR_RIGI = mel)
matas = ASSE_MATRICE (NUME_DDL = nu, MATR_ELEM = mel,)
```
