# CALC_MATR_ELEM operator

## 1 Purpose

Compute element matrices that can then be assembled with the command ASSE_MATRICE.

The possible calculation options are:

```text
'AMOR_ACOU','MASS_MECA','RIGI_FLUI_STRU','RIGI_ROTA','AMOR_MECA',
'MECA_GYRO','MASS_MECA_DIAG','RIGI_GEOM','RIGI_THER',
'MASS_THER','IMPE_MECA','RIGI_MECA','MASS_ACOU','ONDE_FLUI',
'RIGI_MECA_HYST','MASS_FLUI_STRU','RIGI_ACOU','RIGI_GYRO'
```

Produces a data structure of type matr_elem_*.

### 3.2 Operands MODELE / CHAM_MATER / CARA_ELEM

```text
♦  MODELE = mo
```

This operand indicates the elements for which the element calculations must be done: recall that most of the finite elements are defined in the model.

There are two exceptions:

<!-- page 7 -->

1) The elements that enforce the DIRICHLET conditions with Lagrange multipliers, that is, the elements used to impose conditions on the displacement degrees of freedom in mechanics, the temperature degrees of freedom in thermal analysis and the pressure degrees of freedom in acoustics. 2) The nodal load elements.

These elements are defined in the result objects of type char_meca, char_ther or char_acou.

The argument l_char must therefore be given for the calculation of the element stiffness matrices:

```text
   RIGI_MECA,RIGI_THER,RIGI_ACOU,RIGI_MECA_HYST.
◊  CHAM_MATER = chmat
```

Name of the material field where the material properties of the elements are defined.

This argument is almost always needed.

In practice, it can be left out:

  - for discrete elements whose element matrices are defined in the cara_elem result object. See AFFE_CARA_ELEM [U4.42.01],
  - for the calculation of the stiffnesses due to the Lagrange-multiplier enforcement of the boundary conditions.

```text
◊  INST = tps
```

The argument tps is used when the material properties or the loads depend on time. A fairly frequent case is that of a mechanical material that depends on the temperature, which itself depends on time.

```text
◊  CARA_ELEM = carac
```

The element properties carac are needed if the model contains beam, shell or discrete elements, or if an anisotropy coordinate system has been defined on solid elements (keyword MASSIF of the command AFFE_CARA_ELEM).

### 3.3 Operand CHARGE

```text
◊  CHARGE = char
```

This operand has several distinct functions:

1) Allow the calculation of the element stiffness matrices that correspond to the Lagrange-multiplier enforcement of some Dirichlet boundary conditions, 2) For the option 'ONDE_FLUI': give the value of the pressure of the incident wave, 3) For the option 'RIGI_ROTA': give the value of the rotation imposed on the model.

### 3.4 Operand MODE_FOURIER

```text
◊  MODE_FOURIER =  / nh
                   /   0         [DEFAUT]
```

Positive or zero integer giving the Fourier harmonic on which the element matrices are computed.

### 3.5 Operand CALC_ELEM_MODELE

```text
◊  CALC_ELEM_MODELE =  / 'OUI'                                    [DEFAUT]
                       / 'NON'
```

This operand computes the element stiffness matrix associated only with the macro-elements of the model ('NON'). By default, the matrix is computed on the whole model ('OUI').

<!-- page 8 -->

### 3.6 Operand GROUP_MA

```text
◊  GROUP_MA = lgma,
```

This operand computes the element matrices only on the elements of the groups lgma. The operand is allowed for the gyroscopic options, RIGI_MECA, RIGI_MECA_HYST, AMOR_MECA, MASS_MECA, IMPE_MECA, MASS_MECA_DIAG and MASS_FLUI_STRU.

### 3.7 Operand SIEF_ELGA (option 'RIGI_GEOM')

```text
♦  SIEF_ELGA = sig
```

The stress field sig given for the calculation of the option 'RIGI_GEOM' should in principle have been computed with the option 'SIEF_ELGA' (stress field at the Gauss points of the elements) (see command CALC_CHAMP [U4.81.04]). Linear buckling theory indeed assumes a theory of small elastic displacements.

### 3.8 Operands RIGI_MECA and MASS_MECA (options 'AMOR_MECA' and

```text
'RIGI_MECA_HYST')
  ♦  RIGI_MECA =
```

Real part of the element stiffness matrices ('RIGI_MECA') needed to compute the matrices:

  - of damping ('AMOR_MECA')
  - of hysteretic stiffness by global hysteretic damping ('RIGI_MECA_HYST'), see «Notice d'utilisation de l'amortissement et de la rigidité hystérétique» [U2.06.03].
  - of complex stiffness for viscoelastic materials; the option 'RIGI_MECA_HYST' computes the imaginary part of the element stiffness matrix and assembles it with the real part passed as argument of the option.

```text
◊  MASS_MECA =
```

Element mass matrices ('MASS_MECA' or 'MASS_MECA_DIAG') needed to compute the damping matrices ('AMOR_MECA').

Remark:

For the option 'RIGI_MECA_HYST' , the result of the calculation will contain, in addition to the hysteretic stiffness of the elements of the model, the matrix associated with the Lagrange multipliers induced by the Lagrange-multiplier enforcement of the given loads.

Remark:

For a model that contains only massless finite elements (for example '3D_ABSO' or 'D_PLAN_ABSO'), the user can build a damping matrix without having to build a mass matrix by using the operator ASSEMBLAGE.

### 3.9 Operands AMOR_FLUI and VNOR

```text
◊  AMOR_FLUI =
```

This option deactivates the contribution of the fluid absorbing boundaries ('3D_FLUI_ABSO', '2D_FLUI_ABSO' and 'AXIS_FLUI_ABSO'). In particular, when the u−p−φ fluid formulation is used in a harmonic calculation, the contribution of the fluid absorbing boundaries can be taken into account through the calculation of a third-order matrix (with the option IMPE_MECA). This third-order matrix can be used only in a harmonic calculation (operand MATR_IMPE_PHI in DYNA_VIBRA) and makes the matrix symmetric (unlike the calculation of this contribution through AMOR_MECA). The option AMOR_FLUI = 'NON' avoids computing this contribution twice. By default, AMOR_FLUI = 'OUI'. This operand is available only for the option AMOR_MECA.

<!-- page 9 -->

```text
◊  VNOR=
```

This option takes into account the case of an emitting boundary. The most common case is the radiating one (or partially radiating if a reflection coefficient α≠0 is defined). For a radiating boundary VNOR = 1. (option active by default). For an emitting boundary VNOR = -1. This coefficient multiplies the value of the impedance of the fluid absorbing boundaries ('3D_FLUI_ABSO', '2D_FLUI_ABSO' and 'AXIS_FLUI_ABSO'). This operand is available only for the options AMOR_MECA, IMPE_MECA and AMOR_ACOU.

### 3.10 Operand TYPE_AMOR

```text
◊  TYPE_AMOR =
```

This option computes either all the damping sources present in the model or only the source related to the absorbing boundary elements (fluid or not). The default option ( TYPE_AMOR = 'TOUT' ) takes into account any Rayleigh damping, the damping coming from the discrete elements and that coming from the absorbing boundary elements. In this case either the mass and stiffness matrices for the Rayleigh damping (and the material field), or the properties of the discrete elements, must be given. If the only damping is the one coming from the absorbing boundary elements, TYPE_AMOR = 'ABSO' must be given, with only the material field as input.

## 4 Examples of calculations with CALC_MATR_ELEM

### 4.1 Geometric stiffness matrix for Euler buckling

```text
rigigeom = CALC_MATR_ELEM (  OPTION ='RIGI_GEOM',    MODELE = mo ,
                             CARA_ELEM = carac   ,   SIEF_ELGA = chsig )
```

### 4.2 "Mass" matrix in acoustics

```text
massacou = CALC_MATR_ELEM (  OPTION ='MASS_ACOU',    MODELE = mo ,
                             CHAM_MATER = chmat  )
```

### 4.3 Stiffness matrix in mechanics

```text
rigibloc = CALC_MATR_ELEM (  OPTION ='RIGI_MECA',    CHARGE = ch_bloc )
```
