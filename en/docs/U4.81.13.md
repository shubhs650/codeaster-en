# MACR_LIGN_COUPE operator

## 1 Purpose

Extract into a table the values of a result along cut lines defined by two points and a number of intervals, or by node groups.

```text
Le résultatpeutêtremécanique(evol_elas,evol_noli,  mode_meca,  comb_fourier,
mult_elas, fourier_elas, dyna_trans)outhermique(evol_ther).
```

Principle: this macro-command creates a line mesh of straight, regular two-node segments. This mesh can be:

- straight, defined by its end points and the number of intervals it is made of;
- curved, defined by the center and angle of a circle, the first point of the cut line, the number of points wanted, and possibly a vector normal to the plane that contains the cut line (in 3D only);
- arbitrary, when the cut line is a path through the nodes of a node group.

The fields of the result given (displacement or temperature by default) are projected onto this mesh with the command PROJ_CHAMP. Then the nodal values along the cut line of the field to post-process are collected in a table by POST_RELEVE_T. This table is what the macro-command produces.

## 3 Operands

### 3.1 Operand RESULTAT/CHAM_GD

```text
♦   / RESULTAT  =  resu,     [evol_elas, evol_noli, mode_meca, evol_ther,
                             comb_fourier, mult_elas, fourier_elas,
                             dyna_trans]
```

Name of the result object of type evol that contains the field to post-process

```text
/  CHAM_GD   =  champ, [cham_no_DEPL_R, cham_no_TEMP_R,
                        cham_no_SIEF_R, cham_elno_SIEF_R]
```

Name of the field object to post-process. The optional keyword MODELE must be given whenever CHAM_GD is present.

### 3.2 Operands NUME_ORDRE / NUME_MODE / LIST_ORDRE / INST /

```text
LIST_INST / PRECISION / CRITERE
```

See documentation [U4.71.00]

### 3.3 Operand NOM_CHAM

```text
♦  NOM_CHAM        =   /  ’SIGM_NOEU’, [DEFAUT si mécanique]
                       /  ’TEMP’,             [DEFAUT si thermique]
                       /  champ,              [K16]
```

Name of the field of the result resu whose values are to be read along a cut line. If this keyword is not given, the default projected field is the stress field at nodes computed from the displacements for a mechanical result, and the temperature for a thermal result.

Note:

The macro-command handles all field types: NOEUD , ELEM , ELNO .

Using it for the ELNO field type is not advised, because the result of projecting an ELNO field with PROJ_CHAMP is sometimes a little confusing: a node gets its value from one of the elements that contain it. More details in Chapter 3.13 [u4.72.05].

### 3.4 Operand MODELE

```text
◊  MODELE    =  modele,   [modele]
```

Name of the model associated with the result object evol_xxx. The model is needed when PROJ_CHAMP projects the field.

### 3.5 Operand UNITE_MAILLAGE

```text
◊  UNITE_MAILLAGE  =   25,   [DEFAUT]
```

Gives the logical unit in which the line mesh of the cut line is created. This unit is 25 by default; the user can change it in case unit 25 is already used for something else in the study.

### 3.6 Operands VIS_A_VIS

```text
◊  VIS_A_VIS       =   _F(
      ♦   GROUP_MA_1   =  gma,   [l_K8]))
```

<!-- page 5 -->

This factor keyword is used by the operator PROJ_CHAMP; with its operand GROUP_MA_1 it restricts the extent of the field to project. See the documentation [U4.72.05] for more information.

### 3.7 Keyword LIGN_COUPE

```text
♦  LIGN_COUPE   =  _F(
```

Repeatable keyword that defines one or more cut lines. A cut line is made of 2-node segments that can describe:

- a straight line,
- a circular arc or a circle,
- an arbitrary broken line.

In the first case, the cut line is one straight segment, defined by its two end points and a number of regular intervals that divide it. In the second case, the cut line is made of uniform straight segments whose union forms a circular arc or, as a special case, a circle. In the third case, the cut line is defined from node groups or element groups of the mesh: the cut line is then the path defined by the succession of the nodes of the group.

#### 3.7.1 Operand INTITULE

```text
♦  INTITULE  =      txt,  [Kn]
```

Label in the table that tells the different cut lines apart. If this keyword is not given, the label is ‘l.coupe(n)’, where (n) is the occurrence number of the cut line.

#### 3.7.2 Operand TYPE

This keyword sets the type of cut line to create. It can be SEGMENT , GROUP_NO , GROUP_MA or ARC .

##### 3.7.2.1 TYPE='SEGMENT'

The cut line is a straight segment, defined by its two end points and a number of regular intervals that divide it.

##### 3.7.2.2 TYPE='GROUP_NO'

The cut line is defined by node groups of the mesh that carries the fields: the cut line is then the path defined by the succession of the nodes of these groups.

##### 3.7.2.3 TYPE='GROUP_MA'

The cut line is built from the nodes of an element group made of SEG elements. The cut line is then the path defined by the succession of the reordered nodes of this group. If the line is closed, say so by giving the origin and end nodes (for example with the keywords GROUP_NO_ORIG and GROUP_NO_EXTR). These 2 nodes must be the same. To impose the orientation of the line, use the keyword VECT_ORIE. For more details on these keywords, see the documentation of the keyword NOEUD_ORDO of the command DEFI_GROUP.

##### 3.7.2.4 TYPE='ARC'

<!-- page 6 -->

The cut line is a circular arc or a full circle. It is defined by the following data:

- a first point, the origin of the circular cut line,
- a second point, the center of the circle,
- an angle (in degrees) that gives the end of the cut line,
- a number of points that make up the cut line,
- a vector normal to the plane that contains the cut line, in 3D only.

#### 3.7.3 Operand NB_POINTS

```text
♦  NB_POINTS    =   nb,   [I]
```

Number of points of the cut line.

#### 3.7.4 Operand COOR_ORIG

```text
♦  COOR_ORIG    =   (x1,y1,[z1]),[l_R]
```

Coordinates of the first point of the cut line: 2 reals in the plane, 3 in space. This keyword is used for TYPE='SEGMENT' or TYPE='ARC'.

#### 3.7.5 Operand GROUP_NO_ORIG

```text
♦  GROUP_NO_ORIG=   gnoA,     [group_no]
```

Name of the node group that defines the first point of the cut line. This group must contain only one node. This keyword is used for TYPE='SEGMENT'.

#### 3.7.6 Operand COOR_EXTR

```text
♦  COOR_EXTR    =   (x2,y2,[z2]),[l_R]
```

Coordinates of the last point of the cut line: 2 reals in the plane, 3 in space. This keyword is used for TYPE='SEGMENT'.

#### 3.7.7 Operand GROUP_NO_EXTR

```text
♦  GROUP_NO_EXTR=   gnoB,     [group_no]
```

Name of the node group that defines the last point of the cut line. This group must contain only one node. This keyword is used for TYPE='SEGMENT'.

#### 3.7.8 Operand GROUP_NO

```text
♦  GROUP_NO  =  gno,   [grno]
```

This keyword extracts the values on a given node group. For fields at nodes, it is exactly like POST_RELEVE_T. This keyword is used only for TYPE='GROUP_NO'.

#### 3.7.9 Operands GROUP_MA and MAILLAGE

```text
♦  GROUP_MA  =  grma,  [l_grma]
```

This keyword passes the group of SEG elements from which the nodes are extracted and reordered before post-processing.

```text
♦  MAILLAGE  =  mail,  [maillage]
```

mail is the mesh object that contains the element group grma.

These keywords are used for TYPE='GROUP_MA'.

<!-- page 7 -->

#### 3.7.10 Operand DNOR

```text
◊  DNOR   =  (xa,ya,[za]),    [l_R]
```

The vector given to this keyword must be normal to the plane that contains the circular cut line. In 2D it is not needed (DNOR = Z vector of the global coordinate system). In 3D it sets the direction in which the cut line is traveled (direct sense). This keyword is used for TYPE='ARC'.

#### 3.7.11 Operand CENTRE

```text
♦  CENTRE    =  (x0,y0,[z0]),    [l_R]
```

Coordinates of the center of the circle that carries the circular cut line. This keyword is used for TYPE='ARC'.

#### 3.7.12 Operand ANGLE

```text
♦  ANGLE  =   theta ,  [R]
```

The angle (in degrees) of the circle that carries the circular cut line which, together with its center, the origin point and the plane that contains the cut line, determines the end of the cut line. This keyword is used for TYPE='ARC'.

#### 3.7.13 Operands DISTANCE_MAX and DISTANCE_ALARME

```text
◊  DISTANCE_MAX    =   distmax,  [R]
◊  DISTANCE_ALARME =   distala,  [R]
```

These keywords are used by the operator PROJ_CHAMP. If the distance between a node of the cut line and the cut mesh is greater than distmax , the node is ignored (no value is read at this node). If the distance between a node of the cut line and the cut mesh is greater than distala , a warning is issued. See the documentation [U4.72.05] for more information.

#### 3.7.14 Operands INVARIANT / ELEM_PRINCIPAUX / RESULTANTE / OPERATION /

```text
NOM_CMP / TRAC_NOR / TRAC_DIR / DIRECTION / VECT_Y/ REPERE
```

See documentation [U4.81.21].

## 4 Example

```text
resu = STAT_NON_LINE (...);
```

```text
tab1 = MACR_LIGN_COUPE (  RESULTAT = resu,
                          LIGN_COUPE =(
                             _F(TYPE= ‘SEGMENT’,
                                 NB_POINTS = 17,
                                 COOR_ORIG = (0.,0.,0.),
                                 COOR_EXTR = (10.,0.,0.),
                                 INTITULE = ‘ligne1’, ),
                             _F(TYPE= ‘SEGMENT’,
                                 NB_POINTS = 25,
                                 COOR_ORIG = (-10.,0.,0.),
                                 COOR_EXTR = (0.,20.,0.),
                                 INTITULE = ‘ligne2’,),
                              )
                       );
```

```text
IMPR_TABLE (TABLE = tab1 )
```

In this example, the values of the displacement of the result resu are read at all calculation times along two cut lines.

The table tab1 contains the step indexes, the curvilinear abscissas, the coordinates of the points and finally the values of the nodal quantity (at the nodes of the line) of the field processed, here the displacement by default.
