# AFFE_CARA_ELEM operator

## 1 Purpose

Assign geometric and material properties to structural elements. The geometric data assigned complement the mesh data.

The properties handled include:

- for shell elements: the thickness, a reference direction in the tangent plane,
- for beam elements: the properties of the cross-section and the orientation of the principal axes of inertia about the neutral axis, the curvature of curved elements,
- for discrete elements (spring, mass/inertia, damper): the values of the stiffness, mass or damping matrices, assigned directly or after orientation,
- for bar or cable elements: the cross-section area,
- for 3D and 2D continuous-medium elements: local axes with respect to which the user can define anisotropy directions.

The command must be exhaustive for all the structural elements of the model.

This operator produces a structure of type `cara_elem`.

## 3 General operands MODELE and VERIF

### 3.1 Operand MODELE

```text
♦ MODELE = mo
```

Object of type `modele`, produced by the operator AFFE_MODELE [U4.41.01], on which the element properties are assigned. Note that the model must explicitly hold at least one of the structural elements to which the assignment applies (otherwise the calculation stops).

### 3.2 Operand VERIF

```text
◊ VERIF = / ’MAILLE’
```

Argument Meaning Checks that the element type carried by the elements to which a property is assigned is compatible with this property (including the ’MAILLE’ orientations). Otherwise, stops with an error message.

### 3.3 Operand INFO

| ◊ INFO = / 1 | Prints nothing |
|---|---|
| / 2 | Prints to the "MESSAGE" file, for all the elements, the list of values assigned to the elements: • orientation angles in degrees (beams and discrete elements), • properties of the cross-sections of beams and bars, • prints of the elementary matrices (discrete elements). |

## 4 Definition of the assignment domain

The elements of the model mo to which the assignment applies are chosen in two steps:

- the choice of the element type concerned by the assignment (POUTRE, DISCRET, …),
- the elements (of the element type defined) to assign. Choosing the factor keyword that defines the element type (POUTRE, DISCRET, ...) implies that the model holds the matching element types (this is always checked).

The element types concerned depend on the modeling type:

The properties are assigned to the finite elements with the keyword: ’GROUP_MA’.

- If VERIF is not present: in an element group (or node group), the properties are actually assigned only to the elements for which they make sense. For the other elements, the properties are not assigned.
- If VERIF is present: it is also checked that all the elements of the group are of the right type; otherwise an error message is issued.

## 8 Keyword COQUE

### 8.1 Properties that can be assigned

The properties that can be assigned on plate or shell elements are:

- for all the elements of this type, a constant thickness on each element, since the mesh only represents the mid-surface (or the reference surface for offset shells),
- for all the elements of this type, the number of layers used for integration through the thickness,
- for all the elements of this type, the orientation of the local coordinate system of each element,
- for some shell models, particular properties: shear coefficient, metric, offset, etc.

### 8.3 Operands

#### 8.3.1 Operand EPAIS

```text
♦ / EPAIS    = ep
  / EPAIS_FO = epfct
```

EPAIS is the thickness of the shell, which must be expressed in the same units as the coordinates of the mesh nodes. EPAIS_FO is a function that gives the thickness of the shell, in the same units as the coordinates of the mesh nodes. This function depends on the geometry (X,Y,Z) and is evaluated at the center of gravity of the element.

<!-- page 14 -->

#### 8.3.2 Operands EXCENTREMENT / EXCENTREMENT_FO

```text
◊ EXCENTREMENT     = / e (0.0),                              [réel (défaut)]
   EXCENTREMENT_F0  = efct                                     [ fonction ]
```

EXCENTREMENT : defines the distance between the meshed surface and the mean surface, along the normal (modeling types DKT, DST, GRILLE_EXCENTRE). EXCENTREMENT_FO : function that gives the distance between the meshed surface and the mean surface, along the normal (modeling types DKT, DST, GRILLE_EXCENTRE). This function depends on the geometry (X,Y,Z) and is evaluated at the center of gravity of the element.

Taking the offset into account affects the bending behavior and possibly the membrane behavior when there is coupling (there is no effect on shear).

#### 8.3.3 Operands MODI_METRIQUE / COEF_RIGI_DRZ / INER_ROTA

```text
◊ MODI_MET RIQUE = ’NON’
```

Assumes that the thickness of the element is small. The integrations through the thickness do not take into account the variation of the radius of curvature (default option for all shells).

```text
◊ MODI_MET RIQUE = ’OUI’
```

For the modeling type COQUE_AXIS, the integrations take into account the variation of the radius of curvature through the thickness; see for example [R3.07.02]

```text
◊ INER_ROTA = ’OUI’
```

Takes the rotational inertia into account for the modeling types DKT, DST and Q4G. It is required with an offset. This keyword can be omitted for thin shells, where the rotational inertia terms are negligible compared with the others in the mass matrix [R3.07.03].

```text
◊ COEF_RIGI_DRZ = KRZ,
```

KRZ is a fictitious stiffness coefficient (necessarily small) on the rotational degree of freedom about the normal to the shell. It is needed to prevent the stiffness matrix from being singular, but must be chosen as small as possible. The default value of 10−5 suits most situations (it is a relative value: the stiffness about the normal equals KRZ times the smallest diagonal term of the element stiffness matrix). For DKT there are two operating modes: COEF_RIGI_DRZ negative and COEF_RIGI_DRZ positive. With COEF_RIGI_DRZ positive, the degree of freedom DRZ always has the meaning of a fictitious rotation that prevents the matrix from being singular in the global coordinate system. With COEF_RIGI_DRZ negative, the rotation kinematics of the plate element about its normal is reinforced through a variational formulation. The degree of freedom DRZ then has a physical meaning. A value of 10−8 is recommended.

Remark: Warning: in STAT/DYNA_NON_LINE, this coefficient can cause additional Newton iterations (more than one iteration for a linear problem, for example).

## 9 Keyword POUTRE

### 9.1 Properties that can be assigned

This keyword assigns the cross-section properties of beam elements (modeling types POU_D_E, POU_D_EM, POU_D_T, POU_D_TG, POU_D_TGM, POU_D_T_GD, TUYAU_3M, TUYAU_6M). Several types of section, given by the operand SECTION, can be handled:

- GENERALE : The mechanical properties are given.
- RECTANGLE : The dimensions of the section are given. Code_Aster computes the mechanical properties needed: area, inertias, ...
- CERCLE : The dimensions of the section are given. Code_Aster computes the mechanical properties needed: area, inertias, ...
- COUDE : Defines the correction coefficients of the inertias and the stress amplification coefficients when the ovalization of the section, which beam theory cannot represent, is to be taken into account. The mechanical properties are given by SECTION, which can take the value GENERALE or RECTANGLE or CERCLE.

For each type of section, different properties can be assigned, identified by one or more names (operand CARA) with as many associated values (operand VALE). For the general section, the properties can also be given through a table; see the documentation of the command MACR_CARA_POUTRE. Beams of constant section (property name without suffix) or of variable section (property name with suffix 1 or 2) can be handled. The way the section varies is defined by the keyword VARI_SECT (see [§9.4.1]). The properties of the section are then given at the initial node (name with suffix 1) and at the final node (name with suffix 2) (“initial” and “final” relative to the numbering of the support element). This keyword must also be used to define the torsion constant for the modeling type (POU_D_EM).

## 12 Keyword DISCRET and DISCRET_2D

### 12.1 Properties that can be assigned

These keywords assign stiffness, mass or damping matrices directly to entities (elements or nodes) that carry elements of type DIS_T, DIS_TR (DISCRET) or 2D_DIS_T, 2D_DIS_TR (DISCRET_2D).

On all entities, matrices can be assigned for the translational degrees of freedom only, T, or for the translational and rotational degrees of freedom, TR. The matrices can be diagonal, D, or full (symmetric or nonsymmetric). In all cases (symmetric, diagonal, full matrices) the numbering convention of the terms is imposed: <!-- equation -->

- for symmetric matrices, only the upper triangle is given, with an imposed convention for numbering the terms (see examples).
- for diagonal matrices, only the diagonal terms are given, with an imposed convention for numbering the terms (see examples).
- for nonsymmetric matrices, all the terms are given, with an imposed convention for numbering the terms (see examples).

The matrices can be assigned:

- to nodes or to elements of type POI1; they are then called nodal matrices, N ,
- to elements of type SEG2; they are then called connection matrices, L .

When matrices are assigned to elements or nodes, the element type DISCRET must first be assigned to these elements or nodes with the operator AFFE_MODELE [U4.41.01].

```text
◊ REPERE  = / ’LOCAL’,
            / ’GLOBAL’,
```

By default, the values of the matrices given for the discrete elements express the corresponding quantities in REPERE = ’GLOBAL’.

To define a particular coordinate system at a node (or element of type POI1), give REPERE = ’LOCAL’ and define this coordinate system with the keyword ORIENTATION [§10].

For a matrix defined on an element of type SEG2, the operand REPERE = ’LOCAL’ refers to the local coordinate system attached to the element (initial node, final node), completed if needed by a twist angle defined by the keyword ORIENTATION [§10].
