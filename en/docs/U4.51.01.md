# MECA_STATIQUE operator

## 1 Purpose

Solve a linear static mechanical problem.

This operator solves either:

- a linear static mechanical problem with superposition of different boundary conditions and different loads,
- a thermo-mechanical analysis for a given list of times.
  - in this case the mechanical properties of the materials can depend on temperature: the object of type cham_mater must then be defined from functions (see operator DEFI_MATERIAU [U4.43.01], operand ELAS_FO),
  - the thermal expansion load can only be determined if the thermal expansion coefficient and the reference temperature have been defined (see operators DEFI_MATERIAU [U4.43.01] and AFFE_MATERIAU [U4.43.03]).

The object produced by this operator is of type evol_elas and contains one or more displacement fields at the different calculation times.

<!-- page 2 -->

## 2 Syntax

```text
mestat[evol_elas] = MECA_STATIQUE   ,  reuse = mestat,
              ( ◊   RESULTAT = mestat ,                        [evol_elas]
                ♦  MODELE =            mo  ,               [modele]
                ♦  |   CHAM_MATER =    chmat  ,            [cham_mater]
                   |   CARA_ELEM =     carac  ,            [cara_elem]
                ◊  EXCIT =(_F(   ♦  CHARGE = char,      /  [char_meca]
                                                        /  [char_cine_meca]
                                 ◊  FONC_MULT= fmult ,  /  [fonction]
                                                        /  [formule]
                             ),)
                ◊  /   INST =          /   tps,            [R]
                                       /   0. ,            [DEFAUT]
                   /   LIST_INST =     /   litps ,         [listr8]
                       ◊  INST_FIN = tf,
                ◊  SOLVEUR = ( ... voir [U4.50.01]  ),
                ◊  OPTION =  /   'SIEF_ELGA',        [DEFAUT]
                             /   'SANS',
                ◊  INFO =    /   1,                        [DEFAUT]
                             /   2,
                ◊  TITRE =   titre,                        [l_K80]
             )
```

## 3 Operands

### 3.1 Operands MODELE / CHAM_MATER / CARA_ELEM

These give the arguments needed to compute the stiffness matrix (and the right-hand side):

```text
♦  MODELE =  mo,
```

Name of the model whose elements are the subject of the mechanical calculation.

```text
♦  CHAM_MATER = chmat,
```

Name of the material field.

```text
◊  CARA_ELEM =  carac,
```

Name of the characteristics of the structural elements (beam, shell, discrete, ...) if the model uses them.

### 3.2 Keyword EXCIT

The boundary conditions and the loads are defined here.

```text
◊  EXCIT =
```

This factor keyword defines several objects of type `charge`, one per occurrence; the solution is computed by superposing the effects of the different loads applied.

#### 3.2.1 Operands CHARGE / FONC_MULT

```text
♦  CHARGE = char,
```

Name of an object of type char_meca produced by AFFE_CHAR_MECA or AFFE_CHAR_MECA_F [U4.44.01] from the model mo.

The name of a "kinematic load" (type char_cine_meca), result of the operators AFFE_CHAR_CINE and AFFE_CHAR_CINE_F [U4.44.03], can also be given.

```text
◊  FONC_MULT = fmult,
```

Name of an object of type function (or formula) that defines, for each calculation time, a multiplier applied to the load char.

fmult is a function of time: by default it is a constant function equal to 1.

### 3.3 Keywords INST / LIST_INST

```text
◊  /  INST = tps,
```

Keyword used to run the calculation at a single time tps, with the temperature of that time.

```text
/  LIST_INST = litps,
   ◊   INST_FIN = tf,
```

The list litps produced by DEFI_LIST_REEL [U4.34.01] defines the times at which a thermo-mechanical evolution is to be computed. The keyword INST_FIN restricts the calculation to the times earlier than or equal to tf. This keyword (INST_FIN), combined with the keyword "RESULTAT" (reentrant command), splits a long thermo-mechanical transient into parts.

For example:

```text
resu = MECA_STATIQUE (...     LIST_INST = linst, INST_FIN = 10., ...)
MECA_STATIQUE (RESULTAT = resu,  LIST_INST = linst, INST_FIN =
20., ...)
MECA_STATIQUE (RESULTAT = resu,  LIST_INST = linst, INST_FIN = 30.,
…)
```

### 3.4 Keyword RESULTAT

To continue a calculation that has already run, RESULTAT says which object is enriched. In this case, the command simply does not recompute the earlier times already computed.

### 3.5 Factor keyword SOLVEUR

See [U4.50.01].

### 3.6 Operand OPTION

```text
◊  OPTION = / 'SANS'      / 'SIEF_ELGA'
```

By default the MECA_STATIQUE command computes the stresses at the Gauss points (or generalized forces for structural elements). The other post-processing options are computed afterwards with the command CALC_CHAMP [U4.81.04]. If the user gives OPTION = 'SANS', these stresses are not computed and the data structure produced is smaller.

### 3.7 Operand INFO

```text
◊  INFO = 1,
```

Prints the main characteristics of the linear systems to solve: number of unknowns, size of the matrix.

### 3.8 Operand TITRE

```text
◊  TITRE = titr,
```

Title to give to the result [U4.03.01].

## 4 Examples of calculations

### 4.1 Static calculation with superposition of 2 load cases

```text
mest1 = MECA_STATIQUE (   MODELE = mo,  CHAM_MATER = chmat,
                CARA_ELEM = carac,
                EXCIT = ( _F( CHARGE = ch1 , FONC_MULT = COS ),
                          _F( CHARGE = ch2 ),),  )
```

### 4.2 Thermo-elastic calculation at different times

```text
chmat = AFFE_MATERIAU (   ..., AFFE_VARC=_F(... EVOL=evoth ...) );
mest2 = MECA_STATIQUE (   MODELE = mo , CHAM_MATER = chmat ,
                          EXCIT = _F( CHARGE = bloq ),
                          LIST_INST = litps )
```

## 5 Note

For some linear elastic studies in which the stiffness of the structure does not depend on the thermal history and the kinematic boundary conditions do not depend on the other loads, the deformed shapes for several load cases can be determined with MACRO_ELAS_MULT [U4.51.02].
