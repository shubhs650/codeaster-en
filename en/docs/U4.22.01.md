# DEFI_GROUP operator

## 1 Purpose

Define new node groups or element groups in an existing mesh. This can make it easier to define new geometric locations for data input or post-processing.

New groups are created with topological, logical or geometric criteria.

It modifies a data structure of type `maillage`, `squelette` or `grille`.

## 3 Operands

### 3.1 General remarks on the operands

This command treats objects of type `maillage` or `squelette` the same way. Below, the word "mesh" is used.

This command defines new element groups (or node groups) in an existing mesh: the mesh ma is enriched. No new element and no new node are created. They must already be present in the mesh to be used.

A new group can be defined in several ways:

- by a Boolean operation on existing groups: intersection (INTERSEC), union (UNION) or difference (DIFFE),
- by a geometric criterion: elements with a node inside a given sphere, …
- for node groups, by reference to existing element groups. The node group defined this way holds all the nodes of the elements of the original element group (keywords TOUT_GROUP_MA and GROUP_MA).

The operator processes the keyword CREA_GROUP_MA first, so that the element groups defined there can be used in the keyword CREA_GROUP_NO.

Each occurrence of a keyword CREA_GROUP_MA(_NO) defines a new named group (keyword NOM). This new group can then be reused in the following occurrences to define new groups by intersection, union, ...

The keywords DETR_GROUP_MA and DETR_GROUP_NO "destroy" element or node groups. The elements and nodes of these groups are not removed; only the definitions of the groups are deleted. These keywords are useful, for example, in Python loops that create a group at each iteration: the group is destroyed first and then recreated under the same name. This avoids changing the group name at each iteration.

Note that most features of DEFI_GROUP can be done directly in the SMESH module of SALOME, namely:

- Boolean operations on existing groups,
- creating a group by element type (SMESH filter Type ),
- by a geometric criterion (SMESH filter LyingOn),
- by a normal-angle criterion for surface elements (SMESH filter Coplanar),
- for element groups based on node groups (SMESH function ' Group based on nodes of other groups '),
- for node groups, by reference to existing element groups (SMESH function ' Group based on nodes of other groups '),
- deleting groups.

### 3.3 Keywords DETR_GROUP_MA and DETR_GROUP_NO

These two factor keywords delete the definition of element or node groups. They are sometimes needed because the code stops with a fatal error when trying to create a group whose name is already used. The group must be destroyed before its name can be reused. The two keywords behave the same way, and only DETR_GROUP_MA is described here.

Syntax:

```text
DETR_GROUP_MA=_F(NOM=(gm1,gm2, ...)),
```

The factor keyword DETR_GROUP_MA can in principle be repeated, but this is never necessary because the keyword NOM accepts a list of names of groups to destroy (gm1,gm2, …).

<!-- page 10 -->

Note that all the occurrences of the keyword DETR_GROUP_MA are processed before those of the keyword CREA_GROUP_NO, because the purpose of this keyword is to make the destroyed name reusable. Note also that destroying a group that does not exist gives no warning message. These choices allow, for example, the following in a Python loop:

```text
for i in range(n) :
   DEFI_GROUPE(reuse=MA, MAILLAGE=MA,
             DETR_GROUP_MA=_F(NOM('GM1',),
             CREA_GROUP_MA=_F(NOM='GM1', ...
```

At the first iteration, the group 'GM1' does not exist; its destruction is requested but no warning message is issued.

Remark:

Since the destructions happen at the start of the command, a group cannot be modified with a single call to DEFI_GROUP . For example, a group cannot be "grown" (in a loop) by adding a small group ( b1 ) to it:

```text
for i in range(n):
   b1=nouveau groupe ...
   DEFI_GROUP(reuse=MA,MAILLAGE=MA,
   CREA_GROUP_MA=_F(NOM='tout', UNION=('tout','b1'),),)
```

To do this, call DEFI_GROUP twice:

```text
for i in range(n):
   b1=nouveau groupe ...
   DEFI_GROUP(reuse=MA,MAILLAGE=MA,
       DETR_GROUP_MA=_F(NOM='tout2'),
       CREA_GROUP_MA=_F(NOM='tout2', UNION=('tout','b1'),),)
   DEFI_GROUP(reuse=MA,MAILLAGE=MA,
       DETR_GROUP_MA=_F(NOM='tout'),
       CREA_GROUP_MA=_F(NOM='tout', UNION=('tout2','b1'),),)
```

### 3.4 Keyword CREA_GROUP_MA

```text
|  CREA_GROUP_MA
```

One occurrence of this factor keyword defines a new element group.

#### 3.4.1 Operand NOM

```text
♦  NOM = gma
```

Gives the name (with "quotes") of the new element group.

#### 3.4.2 Operand TYPE_MAILLE

```text
◊  TYPE_MAILLE= /'TOUT'/'3D'/'2D'/'1D'   (DEFAUT='TOUT')
                /'SEG2'/'TRIA3'/'QUAD4'/.../'PYRAM13'
```

This keyword filters the elements put in the new element group. By default there is no filter, but if the user writes for example TYPE_MAILLE='2D', the group created holds only surface elements. The user can also filter the group for a particular element type (TRIA3, HEXA27, …). All element types (POI1,SEG2,SEG3,SEG4, …, PYRAM13) are allowed.

<!-- page 11 -->

Examples:

```text
CREA_GROUP_MA=_F(NOM='VOLUM', 'TOUT='OUI', TYPE_MAILLE='3D')
```

creates the group of all the volume elements (HEXA, PENTA, ...) of the mesh.

```text
CREA_GROUP_MA=_F(NOM='VOLH27',                       'GROUP_MA='GMA1',
TYPE_MAILLE='HEXA27')
```

creates the group of all the elements of type 'HEXA27' in the GROUP_MA. GMA1.

#### 3.4.3 Operand TOUT

```text
/  TOUT = 'OUI'
```

This keyword defines a group holding all the elements of the mesh.

#### 3.4.4 Operand INTERSEC

```text
/  INTERSEC = (gma1, gma2, gma3,...),
```

The new element group is obtained by taking all the elements of gma1 that also belong to gma2, gma3,.... The order of the elements stays that of gma1.

#### 3.4.5 Operand UNION

```text
/  UNION = (gma1, gma2, gma3,...)
```

The new element group is obtained by taking all the elements of gma1, then adding the elements of gma2 that do not belong to gma1, then those of gma3 that belong neither to gma1 nor to gma2, etc.

#### 3.4.6 Operand DIFFE

```text
/  DIFFE = (gma1, gma2, gma3,...)
```

The new element group is obtained by taking all the elements of gma1 that do not belong to the other groups of the list. The order of the elements stays that of gma1.

## 1 st possibility:

A group of a single element is created, giving the element wanted with the keyword POSITION.

Example:

```text
CREA_GROUP_MA = _F (   GROUP_MA = G1,   POSITION = 'INIT' ,NOM = G1I )
```

The group G1I holds the 1st element of the group G1.

## 2 nd possibility:

A group is created holding the elements between the ranks nuini and nufin (inclusive) of an existing group.

Example:

```text
   CREA_GROUP_MA=_F (GROUP_MA = G1, NUME_INIT = 3,   NUME_FIN = 7,NOM =
G1P)
```

The group G1P holds the elements 3, 4, 5, ..., 7 of G1.

Warning:

These keywords use the order of the elements in an element group. This order is often unknown to the user. It can depend on the preprocessor. It is the order of the elements when the GROUP_MA is defined in the Aster mesh file.

#### 3.4.8 Operand OPTION = 'FACE_NORMALE'

```text
/  OPTION = 'FACE_NORMALE'
```

This option defines a GROUP_MA made of surface elements whose normal is parallel to the direction of the vector given by its components with the keyword VECT_NORMALE, or to that of the first vector of the new basis defined by the change of coordinate system given by the nautical angles.

In 3D, the surface elements are assumed to be plane facets. They are of type TRIA3, TRIA6, QUAD4, QUAD8 or QUAD9. Writing X , X , and X for the position vectors 1 2 3 of the first three corner nodes of the element, the normal is given by the cross product: X −X ∧X −X . 2 1 3 1 <!-- equation -->

In 2D, the surface elements are assumed to be straight segments. They are of type SEG2 or SEG3. Writing X and X for the position vectors of the two end nodes 1 2 of the element, the normal is defined by X −X ∧z where z is the unit vector 2 1 perpendicular to the plane and 0. is assigned as the third component of X −X . 2 1 <!-- equation -->

Remark:

A "facet" element is kept if its normal is collinear with the normal vector given by VECT_NORMALE . This condition must hold within a given precision (keyword ANGL_PREC ).

Choosing an ANGL_PREC (for example 30. degrees) in fact defines the group of elements whose normal lies in the cone with axis VECT_NORMALE and apex angle ANGL_PREC .

This can be used (for example) to group the elements of a spherical half-shell ( ANGL_PREC = 90.).

```text
◊  ANGL_PREC =  a
```

The tolerance, in degrees, accepted on the angle between the vector given by the user and the normal vector to the surface element for the two vectors to be considered as having the same direction.

The default value of a is 0.5 degree.


If it is given the value 'OUI', the GROUP_MA is made of the surface elements whose normal is parallel to, and has the same orientation as, the vector given by the user.

The default value is 'OUI'.

### 3.5 Keyword CREA_GROUP_NO


One occurrence of this factor keyword defines a new node group (for the keywords GROUP_MA and TOUT_GROUP_MA, several node groups are created "at once").



##### 3.5.10.1 Closed lines

<!-- page 21 -->

If the line is a loop, its ends cannot be found automatically. To define the origin of the curvilinear abscissas, the user can give the origin and end nodes. These 2 nodes must be identical. The user can also write: ORIGINE='SANS'. The «origin» node is then taken at random on the closed line.

#### 3.5.11 Operand OPTION = 'TUNNEL'

This option creates the `group_no` made of the nodes inside a "tunnel" whose axis and radius are given. The nodes kept are those whose distance to the axis is less than the radius.

The axis of the tunnel must have an "origin" defined by the keyword GROUP_NO_ORIG.

The keyword RAYON defines the "radius" of the tunnel.

The tunnel can be limited by giving its length with the keyword LONGUEUR. This length is measured from the origin of the tunnel.

The candidate nodes for the tunnel are those carried by the elements given by the keywords TOUT='OUI' and GROUP_MA.

#### 3.5.12 Operand OPTION = 'INCLUSION'

```text
/  OPTION =  'INCLUSION' ,
   ♦   GROUP_MA     = lgma,         [l_group_ma]
   ♦   CAS_FIGURE     =   / '2D'
                          / '3D'
                          / '2.5D'
   ◊   DISTANCE_MAX = distma
   ♦   GROUP_MA_INCL = lgma_inc  ,  [l_group_ma]
   ◊   MAILLAGE_INCL = ma_inc ,     [maillage]
```

This option creates the group of the nodes of the elements of lgma that lie geometrically inside the elements of lgma_inc. If MAILLAGE_INCL is not given, lgma_inc is a list of GROUP_MA of the mesh being enriched (ma). Otherwise they are GROUP_MA of ma_inc.

The keyword CAS_FIGURE is required; it says which elements of lgma_inc are used to determine the inclusion: '2D' : only the surface elements (TRIA and QUAD) of a 2D mesh (plane XOY ) are considered. '3D' : only the volume elements (TETRA, PENTA, …) are considered. '2.5D' : only the surface elements (TRIA and QUAD) of a 3D mesh (shell) are considered.

The keyword DISTANCE_MAX is optional. It gives a small tolerance for deciding whether a node is inside an element. A node lying «exactly» on an interface between 2 elements risks being considered «outside» both elements, and therefore not part of the inclusion. This is why the code takes a default value of distma: 1% of the length of the shortest edge of the mesh ma_inc. For a «shell» type mesh (2.5D), if the surface is not plane, a facet element is almost never geometrically inside other elements: there is nearly always a gap in the direction «normal» to the surface. In this case, a value of distma larger than the default must therefore generally be given.

## 4 Examples

Example 1 (topological and logical criteria):

Let ma be a mesh that already holds the element groups:

```text
M1   M2   M3
```

and the node groups:

```text
N1   N2   N3
ma = DEFI _GROUP (reuse = ma, MAILLAGE = ma,
           CREA_GRO UP_MA = ( _F (   NOM = NM1, GROUP_MA = (GMA7, GMA9,...)   ),
                              _F (   NOM = NM2, UNION = (M1, NM1) ),
                              _F (   NOM = NM3, DIFFE = (NM2, M2) ),),
           CREA_GRO UP_NO = _F   (   TOUT_GROUP_MA = 'OUI '),                 )
ma = DEFI _GROUP (reuse = ma, MAILLAGE = ma,
           CREA_GRO UP_MA = _F   (   NOM = NM4, GROUP_MA = (GMA7, GMA11, GMA1 3))
           CREA_GRO UP_NO = (_F  (   NOM = NN1, INTERSEC=  (NM1, N1)),
                              _F(GROUP _MA = NM4)))
```

After these two calls to the command DEFI_GROUP, the mesh then holds:

- the element groups:

```text
•   M1, M2, M3 (initiaux)
•   NM1 = (mailles : MA7, MA9, ...)
•   NM2 = M1  "union" NM1
•   NM3 = NM2 "moins" M2
•   NM4 = (MAILLES : MA7, MA11, MA13)
```

- the node groups:

```text
•   N1, N2, N3 (initiaux)
```

  - M1, M2, M3, NM1, NM2, NM3 : `group_no` holding the nodes of the `group_ma` with the same names. These `group_no` are created by the 1st DEFI_GROUP command.
  - NN1 = NM1 "intersection" N1
  - NM4 = (nodes of the `group_ma` NM4)

Example 2 (geometric criteria):

```text
ma = DEFI _GROUP   (reuse = ma, MAILLAGE = ma,
           CREA_GRO UP_MA=(_F ( NOM = facesup   ,   OPTION =   'FACE_NORMALE' ,
                                 VECT_ NORMALE = (0.,  0.,  1.)),
                              _F ( NOM  = S01   ,       OPTION =   'SPHERE' ,
                                 POINT  = (0.,  0.,  0.),  RAYON = 1.),),
           CREA_GRO UP_NO =(_F   ( NOM  = BO_S01,   OPTION =   'ENV_SPHERE' ,
                                 POINT =(0.,0.,0.),RAYON=1.,PRECISION=0.01),
                          _F  ( NOM = S01_1 ,   GROUP_MA = S01),
                          _F  ( NOM = S01_2 ,   OPTION = 'ENV_SPHERE'  ,
                                 POINT =(0.,0.,0.),RAYON=0.5,PRECISION=0.5),),
                   )
```

After DEFI_GROUP the mesh ma holds 2 new GROUP_MA and 3 new GROUP_NO:

- facesup holds the facets whose normal points along OZ (toward Z0 ),
- S01 holds all the elements one of whose nodes lies in the sphere of radius 1. centered at O (origin of the axes),
- B0_S01 is the group of the nodes near the surface of the previous sphere (S01),
- S01_1 is the group of all the nodes of the elements of the element group S01; warning: some nodes of this group may lie outside the sphere!
- S01_2 is the group of the nodes inside the sphere S01 : ∣dM ,O−0.5∣≤0.5
